アカウントは御財団の名義のままです。芝原は「運用担当者」として入るだけなので、メンバーの追加・削除や、アカウントそのものの管理はできません。終わったあと、いつでも外していただけます。

STEP 1今の状態を確かめる浅井様・5分

パソコンかスマホで「LINE公式アカウントマネージャー」を開き、次の5つを見てメモしてください。わからない所は空欄で大丈夫です。

  • ログインできるかいつもログインに使っているLINEアカウント、またはメールアドレスで入れるか
  • 浅井様の権限が「管理者」か設定 → 権限管理 の一覧で、浅井様の名前の横に「管理者」と出ているか。管理者でないと、芝原を追加できません
  • 友だちの人数ホーム画面の上に出ている数字
  • 今の料金プラン無料（コミュニケーションプラン）か、ライト・スタンダードか
  • 今使っている機能リッチメニュー（トーク画面の下のメニュー）、あいさつメッセージ、自動の応答、それぞれ使っているか

STEP 2芝原をメンバーに追加する浅井様・3分

設定を代わりに行うための手続きです。発行したURLは24時間で使えなくなるので、発行したらすぐ芝原に送ってください。

  1. 設定を開く画面の右上の 設定
  2. 権限管理を開く左のメニューの 権限管理
  3. メンバーを追加するメンバーを追加 を押す
  4. 権限は「運用担当者」を選ぶ「管理者」ではなく「運用担当者」です。これでメニューやメッセージの設定ができます
  5. URLを発行して、芝原にLINEで送るURLを発行 → 出てきたURLをコピーして、芝原とのトークに貼って送信。このURLは24時間だけ有効で、1人しか使えません
  6. 芝原が承認して完了芝原がURLを開いて承認すると、権限管理の一覧に「芝原」が出ます
あとで外すとき。設定 → 権限管理 で芝原の行から削除できます。

STEP 3中身を一緒に決める打ち合わせ・20分

芝原が案を画面でお見せします。浅井様には、次の7つを「このままでよい／ここを変えたい」で決めていただきます。

決めること芝原の案浅井様に決めていただくこと
リッチメニュー6つ：サロンを探す／イベント／製品を見る／サロンを開きたい方／動画を見る／お問い合わせ並び順と言葉。写真を差し替えたい所があるか
あいさつメッセージ友だち追加のお礼と、「都道府県名を送ると近いサロンをご案内」の一文文面。浅井様らしい言い回しに直すか
都道府県名への自動の返事「福岡」と送られたら、福岡のサロン一覧を返すサロンがない県から来たときの返し方
個別の返信自動の返事と、浅井様が直接返すチャットを両方使う誰が、いつ返信するか（浅井様か事務局か、何日以内に返すか）
ステップ配信友だち追加の1日後・3日後・7日後に、短い読みもの回数と、内容に入れてほしい話
イベントなどの配信決まったときと1週間前に配信。月1回まで財団からのお便り誰が配信するか（財団で送るか、芝原が代わりに送るか）
料金プラン友だちの増え方を見て判断無料のままか、ライト（月5,000円・税別）にするか
通数のこと。無料プランで送れるのは月200通です。ステップ配信も1人に届くたびに数えるので、3回にすると月67人以上友だちが増えたときに足りなくなります。友だちの人数を見てから、一緒に決めましょう。

STEP 4ご用意いただくもの浅井様・できる範囲で

  • サロンの最新の一覧閉じたサロン、新しく開いたサロン、電話番号が変わったサロン。都道府県への自動の返事に使います
  • イベントの予定来月のイベントの日時・会場・参加費と、Select Type の申込ページのURL
  • 写真（あれば）イベントの様子、サロンの雰囲気、財団の方の写真。メニューや配信に使います。なければ今のホームページの写真を使います
  • 「これは言わない」こと配信で触れてほしくない話や、表現の決まりがあれば

STEP 5設定する芝原・2〜3日

  1. リッチメニューを作って設定画像（2500×1686px）を作り、6つのリンク先を設定
  2. あいさつメッセージ決まった文面を設定
  3. 都道府県名への自動の返事「福岡」「福岡県」「ふくおか」などの言い方もまとめて登録
  4. ステップ配信文章を作り、効果をうたう表現がないか確認してから設定
  5. ホームページの「友だち追加」ボタン新しいサイトのLINEボタンを、QR画像ではなく友だち追加のリンクにつなぐ

STEP 6スマホで確かめる浅井様・5分

設定が終わったら芝原からご連絡します。浅井様のスマホで、次を試してください。

  • トーク画面の下にメニューが出るか出ないときは、トーク画面をいったん閉じて開き直すと出ます
  • メニューの6つを押して、それぞれのページが開くか
  • 「鹿児島」と送って、サロンの案内が返ってくるか
  • あいさつメッセージ新しく友だち追加したときにだけ届くので、事務局の方など、まだ友だちでない方に追加してもらって確かめるのが確実です
